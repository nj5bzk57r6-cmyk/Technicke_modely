# Atlas ocelí

Samostatná webová aplikace pro vyhledání meze pevnosti, meze kluzu a použití vybraných materiálů podle původní ČSN.

## Spuštění

- [Otevřít aplikaci přes GitHub Pages](https://nj5bzk57r6-cmyk.github.io/Technicke_modely/Atlas%20ocel%C3%AD/)
- Naskenovat soubor `qr-kod.png` telefonem.

Aplikace je tvořena jediným souborem `index.html` a nepotřebuje instalaci ani serverovou část.
